IT Direction: Software Engineering and Data Science

This page covers the two main study tracks at HZ, my personal choice, and what I plan to do in the future.

Software Engineering

Software Engineering is about building, testing, and maintaining software. It focuses on how code is structured, how systems scale, and how services communicate.

  • Core topics: OOP, web frameworks, APIs, DBs, Git, Docker, and system architecture.
  • Typical roles: Backend developer, full stack developer, DevOps engineer, security consultant.

Data Science

Data Science focuses on collecting, cleaning, and analyzing data to find patterns and train models. It is heavily based on statistics, mathematics, and machine learning pipelines.

  • Core topics: Python, Pandas, statistical modeling, machine learning, data cleaning, neural networks, and visualization.
  • Typical roles: Data analyst, data engineer, machine learning engineer, business intelligence specialist.

Track Comparison

Comparison Software Engineering Data Science
Focus Building maintainable applications. Analyzing data and building predictive models.
Main tools Python, SQL, Docker, Linux, Git. Python, Pandas and PyTorch (Python libraries), Jupyter notebooks, SQL.
Outcome Working software. Trained models, dashboards, and reports.

My Choice

My chosen direction is going to be software engineer.

Why that direction?
I think I will choose SE because it has more value to me in the future of pentesting, a counter argument could be "data engineer has better ties to LLM pentesting, because you will understand the pipelines better". While that is true, a big part of LLM pentesting will also come back into software engineer.

Concerns
I hate the direction software engineering is getting itself into, I feel like the majority of code (even in critical spaces) is just fully AI generated AND that's not a problem to me! AI has the potential to write better code than any human ever could, BUT it still needs to be checked like the HITL principle implies, and that is disappearing, right now it's ship fast, fix later. It just ruins the love for the game. Also why I am not sure: Since my focus is on security, I'd like to improve myself every chance I get, but the ONE and ONLY chance I get is in year 4 SE, CU75042v2, Web Application Security (WAS in short), and that seems too little for me, and also web security is sometimes a bit boring, binary exploitation, wireless exploitation, privilege escalation exploits just seem way more fun to me!

Future Me

In four years, I see myself having graduated from HZ with an HBO ICT diploma. Alongside my degree, I plan to hold a pentesting certification to further specialize myself. In five years I hope to work as a penetration tester in a cybersecurity focused environment where I can develop myself further. I cannot really choose yet what specific branch I want to specialize in, but that will likely have been decided by the certification I get in year four. I picture myself at a smaller security consultancy or on an internal red team, doing exploitation, scripting my own tooling, and writing reports a developer can actually act on.
