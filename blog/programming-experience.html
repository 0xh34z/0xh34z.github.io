Programming Experience: Servers, Linux, and APIs

17-10-2026

I did not start programming through school lessons. I started because I wanted to run servers and automate things on my own hardware.

How It Started

At twelve I started building computers and repairing laptops. At thirteen I hosted Minecraft servers and spent hours editing server configurations and permissions. In high school I made Linux (Ubuntu 22 or 20 something or Debian 11 if I remember correctly) my main daily OS, which forced me to learn basic CLI.

What I Work With Now

Python is my main language for building tools, since it's a pretty versatile language, you have libraries for everything. I also run a Proxmox server at home for hosting virtual machines and testing deployments. In terms of always on services for 100% uptime, I use an RPi 5 16GB + 256GB HAT running Docker, Portainer and Watchtower to keep everything up to date. I'm planning to upgrade to a Kubernetes cluster because, well, it would reinforce my 100% uptime mentality, and I would learn Kubernetes!

In addition to code, I like doing penetration testing labs on Hack The Box and experimenting with machine learning models.
